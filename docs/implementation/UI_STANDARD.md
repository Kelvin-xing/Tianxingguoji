# 全站 UI 标准（2026-11-16）

本标准来自项目负责人确认的青绿样式及 `ui-style-c/` 六张参考页。参考页的学生、学校、数字与功能只是示意，不能成为业务数据或功能授权。业务以需求库为准，本文件仅约束呈现。首批覆盖登录、今日工作和学校目录；其他页面暂时只更换外壳。

## 固定取值

## 页面规则

- 外壳：白色轻阴影顶部导航，左侧「天星教育」，当前项浅主色底深色粗体；右侧胶囊搜索与主色圆形头像。不用侧栏。沿用现有菜单顺序、文字和权限，管理项收进「管理」；手机换行。没有搜索能力时明确不可用，不伪造结果。
- 首页：主色圆角 24px 总览区，日期、问候、概要、三个深色数字块。主栏最近事项放大，其余按时间列出；副栏关联案件卡。完成按钮、进度、多久未更新等必须有真实数据与既有功能才显示。
- 列表：标题、说明、右侧唯一页面主按钮；搜索筛选后接白卡表格，首列粗体名称和次说明，状态标签，底部分页范围与前后页。学校使用 56px 搜索框和学段快捷筛选。
- 详情：返回、标题、标签与主按钮；必要时胶囊分页签。分组白卡，标签在上值在下；多个同类对象用浅底小块。实际有阶段的对象才呈现分段进度。关联信息可放副栏。
- 编辑：先看后改，点「編輯資料」后仅当前组进入编辑，以 2px 主色外框标示；卡内取消与储存，一组一次保存。页面阅读态主按钮在页头；编辑态移除页头主按钮，以当前卡片保存为主操作；模态框的主操作只在模态框活动期间出现。这是对样式中“页头唯一主按钮”与“编辑卡片主色储存”的冲突处理：优先避免同时展示竞争性主操作，不改变指定配色。
- 次要内容：履历和时间轴用弱化底色、14px 次要字，不用白卡；默认收起或只显示最近几条，提供「查看全部」。恢复旧值先确认。
- 登录：左半主色品牌、标语和说明，右半页面底色上的白卡（电邮、密码、全宽主按钮）；手机上下排列，认证机制不变。

## 空、错、加载、确认与提示

- 空状态：在内容卡内显示简短标题、已有规则允许的说明及可执行的既有动作。不得用虚构记录填满页面，也不得把请求失败当成空数据。
- 错误：提醒浅底、可读文字与重试；不显示内部堆栈或秘密。保存失败保留用户输入；版本冲突不能自动覆盖。
- 加载：文字状态可被辅助技术读出；操作期间防重复提交，保留当前内容上下文，不用假数据骨架数值。
- 确认：原生模态对话框，标题、涉及资料、取消与确认；键盘焦点进入框内，Escape 可取消。恢复旧值明确显示资料项与目标值，取消不发写入请求。
- 提示条：正常主色浅底、需留意提醒浅底；都有文字；使用 status / alert 语义。提示不得代表业务尚未定义的状态。

## 共用组件硬规则

此后新增或改动的页面必须使用共用组件，不得在页面里自行另写一套样式。组件和变量入口是 `components/ui/standard.tsx` 与 `standard.css`。组件包括页面、页头、主色区块、卡片、按钮、标签、资料展示、输入、下拉、搜索、快捷筛选、表格、分页、分页签、分段进度、空状态、提示条及确认框。顶部导航由 `components/layout/TopBar.tsx` 实现。

不引入新组件库：本轮原生控件及现有 React 足以表达标准，减少依赖和默认皮肤冲突。扩展时先补共用组件，不在单页绕过标准。未迁移页面不在本轮重做；不能以样式票改变授权、路由、业务事实或登录机制。

## 验证与边界

离线测试验证分组保存仍逐字段留履历、冲突回滚、分页限量、校址称呼稳定；浏览器验证真实本地合成流程、键盘/响应式与截图。详细证据、未执行项和样式稿未支持元素记录在同名 txgj-doc 实施报告中。静态存在不等于视觉或运行验收通过。
